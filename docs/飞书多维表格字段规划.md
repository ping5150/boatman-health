## 三、创建步骤

### 步骤1：创建睡眠问卷表格
1. 在飞书多维表格中新建表格，命名为"睡眠调研问卷"
2. 按照上述字段列表逐一添加字段，**字段名称必须使用中文列的名称**
3. 设置字段类型和选项值
4. 记录表格的 `app_token` 和 `table_id`

### 步骤2：创建营养问卷表格
1. 在飞书多维表格中新建表格，命名为"营养调研问卷"
2. 按照上述字段列表逐一添加字段，**字段名称必须使用中文列的名称**
3. 设置字段类型和选项值
4. 记录表格的 `app_token` 和 `table_id`

### 步骤3：配置环境变量
创建完成后，将以下信息配置到 `server/.env` 文件中：

```env
# 睡眠问卷飞书配置
SLEEP_SURVEY_APP_TOKEN=your_sleep_app_token
```

## 四、字段映射说明

### 数据库字段 vs 飞书字段

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 数据库字段 | 蛇形命名（snake_case） | `sleep_duration_hours` |
| 飞书字段 | 中文名称 | `睡眠时长（小时）` |

### 映射关系

后端 `feishu.service.ts` 中已实现自动映射，提交数据时会自动将数据库字段名转换为飞书中文字段名：

```typescript
// 示例：睡眠问卷映射
if (submission.sleepDurationHours != null) {
  fields['睡眠时长（小时）'] = submission.sleepDurationHours;
}
```

## 五、注意事项

1. **字段类型说明**：
   - 单选：只能选择一个选项
   - 多选：可以选择多个选项（存储为逗号分隔的字符串）
   - 文本：短文本输入
   - 多行文本：长文本输入
   - 数字：数值类型
   - 附件：图片或文件上传
   - 创建时间：自动记录创建时间

2. **选项值统一**：
   - 频率类选项统一使用：每天 / 每周3-6次 / 每周1-2次 / 每月1-3次 / 几乎不(吃) / 从不(从未吃)
   - 是/否选项统一使用：是 / 否

3. **字段命名规范**：
   - **飞书字段**：必须使用中文，如"睡眠时长（小时）"
   - **数据库字段**：使用蛇形命名法（snake_case），如 `sleep_duration_hours`

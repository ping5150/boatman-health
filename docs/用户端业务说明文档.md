# 船夫健康 用户端业务说明文档

## 一、项目概述

**船夫健康** 是一个面向高净值人群的私人医疗健康管理服务平台，提供从健康咨询、档案管理到专业医疗管家服务的全流程健康管理解决方案。

### 技术栈
- **框架**: React 19 + TypeScript
- **路由**: React Router Dom 7 (HashRouter)
- **HTTP 客户端**: Axios
- **样式**: Tailwind CSS 4
- **构建工具**: Vite 6

---

## 三、页面功能详解

### 1. 登录模块

#### Login (`/login`)
**功能描述**: 用户认证入口，支持新老用户分流

**业务流程**:
1. **第一步 - 输入手机号**: 用户输入11位手机号
2. **检查用户状态**: 调用 `checkUser` API 判断新老用户
3. **分流处理**:
   - **老用户**: 显示密码登录表单
   - **新用户**: 显示注册表单（用户名 + 密码 + 确认密码）

**关键逻辑**:
- 表单验证：手机号格式、密码长度（≥6位）、用户名长度（≥2位）
- 登录成功后保存 Token 和用户信息到 localStorage
- 自动跳转至首页

## 四、API 接口定义

### 1. 认证接口

| 接口 | 方法 | 路径 | 用途 |
|------|------|------|------|
| 检查用户 | POST | `/auth/check-user` | 判断手机号是否已注册 |
| 密码登录 | POST | `/auth/password-login` | 老用户密码登录 |
| 注册 | POST | `/auth/register` | 新用户注册 |
| 发送验证码 | POST | `/auth/send-code` | 发送短信验证码 |
| 验证码登录 | POST | `/auth/login` | 验证码登录 |

#### 接口详情

**checkUser - 检查用户是否存在**
```typescript
// 请求
{ phone: string }
// 响应
{ success: boolean, data: { exists: boolean, username: string | null } }
```

**passwordLogin - 密码登录**
```typescript
// 请求
{ phone: string, password: string }
// 响应
{ success: boolean, token: string, user: { id, phone, username, role } }
```

**register - 注册**
```typescript
// 请求
{ phone: string, username: string, password: string }
// 响应
{ success: boolean, token: string, user: { id, phone, username, role } }
```

---

### 2. 表单接口

| 接口 | 方法 | 路径 | 用途 |
|------|------|------|------|
| 提交咨询表单 | POST | `/form1` | 提交咨询预约申请 |
| 提交健康档案 | POST | `/form2` | 提交完整健康档案 |

#### 接口详情

**submitForm1 - 提交咨询表单**
```typescript
// 请求
{
  name: string,
  phone: string,
  consultationType: string,  // 咨询类型
  preferredTime: string,     // 首选联系时间
  brief: string              // 简要病史
}
// 响应
{ success: boolean, message: string, data: { id, submittedAt } }
```

**submitForm2 - 提交健康档案**
```typescript
// 请求（嵌套结构）
{
  basicInfo: { name, customerId, phone, emergencyContact },
  healthBackground: { currentDiseases, medications, surgeryHistory, allergyHistory, ... },
  lifestyle: { diet, exercise, sleep, stress, anxiety, brainFog }
}
// 响应
{ success: boolean, message: string, data: { id, version, submittedAt } }
```

## 五、核心业务流程

### 1. 用户注册/登录流程

```
用户输入手机号 → 调用checkUser API → 
├── 老用户 → 输入密码 → passwordLogin → 保存Token → 进入首页
└── 新用户 → 填写注册信息 → register → 自动登录 → 进入首页
```

### 2. 咨询预约流程

```
进入咨询页面 → 自动填充用户信息 → 选择咨询类型 → 
填写联系时间 → 描述病史 → 提交表单 → 
跳转成功页 → 等待管家联系
```

### 3. 健康档案管理流程

```
账户中心 → 深度健康档案 → 
├── 查看档案 → HealthProfile（展示现有数据）
└── 编辑档案 → HealthForm（4模块表单）→ 提交 → 成功页
```

### 4. 退出登录流程

```
账户中心 → 退出登录 → 确认弹窗 → 
确认 → 清除Token/User → 清空sessionStorage → 跳转登录页
```

## 六、状态管理

### UserContext（用户上下文）

**提供的能力**:
- `user`: 当前用户信息
- `isAuthenticated`: 登录状态
- `login(user, token?)`: 登录并存储
- `logout()`: 登出并清除

**存储位置**:
- Token: `localStorage.getItem('token')`
- 用户信息: `localStorage.getItem('user')`
- 健康表单临时数据: `sessionStorage.getItem('healthFormData')`

## 七、权限控制

### 路由守卫

以下页面需要登录：
- `/` (首页)
- `/consultation` (咨询预约)
- `/account` 及其子页面

**实现方式**: 在页面组件内通过 `useEffect` 检查 `isAuthenticated`，未登录跳转至 `/login`

### HTTP 拦截

**请求拦截**: 自动在 Header 中添加 `Authorization: Bearer ${token}`

**响应拦截**: 
- 401 错误自动清除本地存储并跳转登录页
- 避免在登录页循环跳转

## 九、总结

**船夫健康用户端** 是一个面向高净值人群的私人医疗健康管理平台前端应用，核心功能包括：

1. **用户认证**: 支持新老用户分流登录、Token 认证
2. **服务展示**: 8步服务流程、品牌故事、案例展示
3. **咨询预约**: 在线提交咨询申请，等待管家联系
4. **健康档案**: 4大模块的深度健康信息采集与管理
5. **账户管理**: 个人信息编辑、设置管理、安全退出

整体设计注重用户体验和品牌调性，采用移动端优先的响应式设计，提供高端、私密的医疗服务体验。

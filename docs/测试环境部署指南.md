## 🚀 部署流程

### 第一步：服务器初始化

SSH 登录服务器后执行：

```bash
# 1. 上传初始化脚本
# 在本地执行：
scp scripts/setup-test-env.sh root@118.145.239.169:/tmp/

# 2. 在服务器执行初始化
ssh root@118.145.239.169
bash /tmp/setup-test-env.sh
```

### 第二步：部署后端

#### 方法 A：从 Git 拉取（推荐）

```bash
# 在服务器执行
cd /www/server/boatman-health-test

# 克隆代码（如果还没有）
git clone https://github.com/your-repo/boatman-health.git .

# 或者从生产环境复制
# cp -r /www/server/boatman-health/server/* /www/server/boatman-health-test/server/

cd server

# 安装依赖
npm install

# 生成 Prisma Client
npx prisma generate

# 运行数据库迁移
npx prisma migrate deploy

# 编译 TypeScript
npm run build

# 复制环境变量（如果有）
# 确保 /www/server/boatman-health-test/server/.env.test 存在
```

#### 方法 B：从本地上传

```powershell
# 在本地 PowerShell 执行
# 1. 打包后端代码
cd server
tar -cf ../server-test.tar --exclude="node_modules" --exclude="*.db" --exclude="*.db-journal" .

# 2. 上传到服务器
scp ../server-test.tar root@118.145.239.169:/www/server/boatman-health-test/server/

# 3. 在服务器解压
ssh root@118.145.239.169
cd /www/server/boatman-health-test/server
tar -xf server-test.tar
npm install --production
npx prisma generate
npx prisma migrate deploy
```

### 第三步：配置环境变量

```bash
# 在服务器创建 .env.test 文件
cd /www/server/boatman-health-test/server
nano .env.test
```

粘贴以下内容（根据实际情况修改）：

```env
# 服务配置
PORT=3001
NODE_ENV=test

# 数据库
DATABASE_URL=file:./test.db

# JWT
JWT_SECRET=test-jwt-secret-key-do-not-use-in-production-2024

# 飞书（测试环境可以不配置，或配置测试表格）
FEISHU_APP_ID=
FEISHU_APP_SECRET=

# 表单1 飞书表格
FORM1_APP_TOKEN=
FORM1_TABLE_ID=

# 表单2 飞书表格
FORM2_APP_TOKEN=
FORM2_TABLE_ID=

# 火山引擎 TOS（可选）
TOS_ACCESS_KEY_ID=
TOS_ACCESS_KEY_SECRET=
TOS_REGION=cn-guangzhou
TOS_ENDPOINT=tos-cn-guangzhou.volces.com
TOS_BUCKET=boatman-health-test
```

### 第四步：启动后端服务

```bash
# 在服务器执行
cd /www/server/boatman-health-test

# 使用 PM2 启动测试服务
pm2 start /path/to/ecosystem.config.js --only server-test

# 或者直接启动
pm2 start server/dist/app.js --name server-test

# 保存 PM2 配置
pm2 save

# 查看状态
pm2 list
pm2 logs server-test
```

### 第五步：部署前端

#### 1. 本地构建测试版本

修改前端配置以指向测试后端：

```typescript
// client/vite.config.ts
proxy: {
  '/api': {
    target: 'http://118.145.239.169:3001', // 测试后端
    changeOrigin: true,
  },
}

// admin/vite.config.ts 同样修改
```

```bash
# 在本地执行
npm run build

# 打包前端产物
cd dist
tar -cf ../frontend-test.tar .
```

#### 2. 上传到服务器

```powershell
# 上传前端
scp frontend-test.tar root@118.145.239.169:/www/server/boatman-health-test/client/
```

```bash
# 在服务器解压
cd /www/server/boatman-health-test/client
tar -xf frontend-test.tar
```

### 第六步：配置 Nginx

创建测试环境 Nginx 配置：

```bash
# 在服务器执行
nano /etc/nginx/conf.d/boatman-health-test.conf
```

粘贴以下内容：

```nginx
# 测试环境 - 前端静态文件服务（端口 3002）
server {
    listen 3002;
    server_name _;

    # 用户端前端
    location / {
        root /www/server/boatman-health-test/client;
        try_files $uri $uri/ /index.html;
    }

    # 管理后台前端
    location /admin {
        alias /www/server/boatman-health-test/admin;
        try_files $uri $uri/ /admin/index.html;
    }

    # API 代理到测试后端
    location /api {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /admin/auth {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /admin/dashboard {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

```bash
# 测试 Nginx 配置
nginx -t

# 重载 Nginx
nginx -s reload
```

## 🚨 常见问题

### 1. 端口被占用

```bash
# 查看端口占用
lsof -i :3001
lsof -i :3002

# 杀死进程
kill -9 <PID>
```

### 2. 数据库迁移失败

```bash
# 删除旧数据库重新迁移
cd /www/server/boatman-health-test/server
rm prisma/test.db
npx prisma migrate deploy
```

### 3. PM2 启动失败

```bash
# 查看错误日志
pm2 logs server-test --err

# 检查环境变量
cd /www/server/boatman-health-test/server
cat .env.test
```

### 4. Nginx 配置错误

```bash
# 测试配置
nginx -t

# 查看错误日志
tail -f /var/log/nginx/error.log
```

## 🚀 部署流程

### 第一步：服务器初始化

SSH 登录服务器后执行：

```bash
# 1. 上传初始化脚本
# 在本地执行：
scp scripts/setup-test-env.sh root@118.145.239.169:/tmp/

# 2. 在服务器执行初始化
ssh root@118.145.239.169
bash /tmp/setup-test-env.sh
```

### 第二步：部署后端

#### 方法 A：从 Git 拉取（推荐）

```bash
# 在服务器执行
cd /www/server/boatman-health-test

# 克隆代码（如果还没有）
git clone https://github.com/your-repo/boatman-health.git .

# 或者从生产环境复制
# cp -r /opt/boatman-health/server/* /www/server/boatman-health-test/server/

cd server

# 安装依赖
npm install

# 生成 Prisma Client
npx prisma generate

# 运行数据库迁移
npx prisma migrate deploy

# 编译 TypeScript
npm run build

# 复制环境变量（如果有）
# 确保 /www/server/boatman-health-test/server/.env 存在
```

#### 方法 B：从本地上传

```powershell
# 在本地 PowerShell 执行
# 1. 打包后端代码
cd server
tar -cf ../server-test.tar --exclude="node_modules" --exclude="*.db" --exclude="*.db-journal" .

# 2. 上传到服务器
scp ../server-test.tar root@118.145.239.169:/www/server/boatman-health-test/server/

# 3. 在服务器解压
ssh root@118.145.239.169
cd /www/server/boatman-health-test/server
tar -xf server-test.tar
npm install --production
npx prisma generate
npx prisma migrate deploy
```

### 第三步：配置环境变量

```bash
# 在服务器创建 .env 文件（基于 .env.test）
cd /www/server/boatman-health-test/server
cp .env.test .env
```

`.env.test` 内容参考（已存在于项目中）：

```env
# 服务配置
PORT=3003
NODE_ENV=test

# 数据库 - 测试环境使用独立的 SQLite 文件
DATABASE_URL=file:./test.db

# JWT - 测试环境使用独立的密钥
JWT_SECRET=test-jwt-secret-key-do-not-use-in-production-2024

# 飞书 - 使用测试环境独立表格
FEISHU_APP_ID=cli_a9f73a62fbf99cb0
FEISHU_APP_SECRET=wiWZPN1D0sbybJPwoYnJReL86zEbGtdn

# 各表单飞书表格（测试环境独立 Token）
# ...详见 server/.env.test
```

### 第四步：启动后端服务

```bash
# 在服务器执行
cd /www/server/boatman-health-test

# 使用 PM2 启动测试服务
pm2 start /path/to/ecosystem.config.js --only server-test

# 或者直接启动
pm2 start server/dist/app.js --name server-test

# 保存 PM2 配置
pm2 save

# 查看状态
pm2 list
pm2 logs server-test
```

### 第五步：部署前端

#### 1. 本地构建测试版本

修改前端配置以指向测试后端：

```typescript
// client/vite.config.ts
proxy: {
  '/api': {
    target: 'http://118.145.239.169:3002', // 测试 Nginx 端口
    changeOrigin: true,
  },
}

// admin/vite.config.ts 同样修改
```

```bash
# 在本地执行
npm run build

# 打包前端产物
cd dist
tar -cf ../frontend-test.tar .
```

#### 2. 上传到服务器

```powershell
# 上传前端
scp frontend-test.tar root@118.145.239.169:/www/server/boatman-health-test/client/
```

```bash
# 在服务器解压
cd /www/server/boatman-health-test/client
tar -xf frontend-test.tar
```

### 第六步：配置 Nginx

创建测试环境 Nginx 配置：

```bash
# 在服务器执行
# 上传项目中已有的配置文件
scp scripts/nginx-test.conf root@118.145.239.169:/etc/nginx/conf.d/boatman-health-test.conf
```

```bash
# 测试 Nginx 配置
nginx -t

# 重载 Nginx
nginx -s reload
```

> 项目中已包含完整的测试环境 Nginx 配置文件：`scripts/nginx-test.conf`，该文件将所有 API 请求代理到 `127.0.0.1:3003`。

## 🚨 常见问题

### 1. 端口被占用

```bash
# 查看端口占用
lsof -i :3003
lsof -i :3002

# 杀死进程
kill -9 <PID>
```

### 2. 数据库迁移失败

```bash
# 删除旧数据库重新迁移
cd /www/server/boatman-health-test/server
rm prisma/test.db
npx prisma migrate deploy
```

### 3. PM2 启动失败

```bash
# 查看错误日志
pm2 logs server-test --err

# 检查环境变量
cd /www/server/boatman-health-test/server
cat .env
```

### 4. Nginx 配置错误

```bash
# 测试配置
nginx -t

# 查看错误日志
tail -f /var/log/nginx/error.log
```

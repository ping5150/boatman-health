# Server 更新部署指南

> 本文档说明如何将 server 代码更新部署到腾讯云服务器。

---

## 快速更新流程

### 1. 本地编译

```powershell
cd f:\全栈项目\boatman-health\server
.\node_modules\.bin\tsc
```

### 2. 打包

```powershell
# 在 server 目录下执行
tar -cf ../server-deploy.tar --exclude="node_modules" --exclude=".env" --exclude="*.db" --exclude="*.db-journal" .
```

### 3. 上传到服务器

```powershell
scp ../server-deploy.tar root@118.145.239.169:/home/chuanfu-health/server/
```

### 4. 服务器端更新

```bash
# SSH 登录服务器
ssh root@118.145.239.169

# 解压并重启
cd /home/chuanfu-health/server
tar -xf server-deploy.tar
rm server-deploy.tar
npm install --production
npx prisma generate --schema=./prisma/schema.prisma
pm2 restart chuanfu-server
```

## 一键部署脚本

### 本地 PowerShell 脚本 (deploy.ps1)

```powershell
# deploy.ps1 - 在 server 目录下执行

Write-Host "🔨 编译 TypeScript..." -ForegroundColor Yellow
.\node_modules\.bin\tsc
if ($LASTEXITCODE -ne 0) {
    Write-Host "❌ 编译失败" -ForegroundColor Red
    exit 1
}

Write-Host "📦 打包文件..." -ForegroundColor Yellow
tar -cf ../server-deploy.tar --exclude="node_modules" --exclude=".env" --exclude="*.db" --exclude="*.db-journal" .

Write-Host "📤 上传到服务器..." -ForegroundColor Yellow
scp ../server-deploy.tar root@118.145.239.169:/home/chuanfu-health/server/

Write-Host "✅ 上传完成！请在服务器执行以下命令：" -ForegroundColor Green
Write-Host @"
cd /home/chuanfu-health/server
tar -xf server-deploy.tar
rm server-deploy.tar
npm install --production
npx prisma generate --schema=./prisma/schema.prisma
pm2 restart chuanfu-server
"@ -ForegroundColor Cyan
```

### 服务器端一键更新脚本 (update.sh)

```bash
#!/bin/bash
# update.sh - 放在服务器的 /home/chuanfu-health/server/ 目录

set -e

echo "📦 解压文件..."
tar -xf server-deploy.tar
rm -f server-deploy.tar

echo "📥 安装依赖..."
npm install --production

echo "🔧 生成 Prisma Client..."
npx prisma generate --schema=./prisma/schema.prisma

echo "🔄 重启服务..."
pm2 restart chuanfu-server

echo "✅ 更新完成！"
pm2 list
```

## 注意事项

1. **数据库迁移**：如果有新的 Prisma 迁移，需要在服务器执行：
   ```bash
   npx prisma migrate deploy --schema=./prisma/schema.prisma
   ```

2. **环境变量**：更新不会覆盖服务器上的 `.env` 文件，无需担心配置丢失。

3. **回滚**：如果更新出现问题，可以从 Git 历史中恢复代码并重新部署。

4. **日志检查**：更新后建议检查日志确认服务正常：
   ```bash
   pm2 logs chuanfu-server --lines 50
   ```

## 常见问题

### Q: 编译报错找不到 tsc

**解决**：先安装依赖
```powershell
npm install
```

### Q: 上传超时

**解决**：检查网络连接，或使用 rsync 替代 scp：
```powershell
rsync -avz --progress ../server-deploy.tar root@118.145.239.169:/home/chuanfu-health/server/
```

### Q: 服务启动后报错

**排查**：
```bash
# 查看错误日志
pm2 logs chuanfu-server --err

# 手动运行查看详细错误
cd /home/chuanfu-health/server
node dist/app.js
```

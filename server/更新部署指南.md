# Server 更新部署指南

> 本文档说明如何将 server 代码更新部署到腾讯云服务器。

---

## 快速更新流程

### 1. 本地编译

```bash
cd server
npm run build
```

### 2. 上传到服务器

```bash
rsync -avz --delete --exclude='node_modules' --exclude='.env' server/ root@106.53.64.33:/www/boatman-health/server/
```

### 3. 服务器端更新

```bash
# SSH 登录服务器
ssh root@106.53.64.33

# 安装依赖并重启
cd /www/boatman-health/server
npm install --production
npx prisma generate
pm2 restart boatman-health --update-env
```

---

## 一键部署脚本

### 本地脚本

```bash
#!/bin/bash
# deploy.sh - 在项目根目录执行

set -e

echo "🔨 编译后端..."
cd server && npm run build

echo "📤 上传到服务器..."
rsync -avz --delete --exclude='node_modules' --exclude='.env' ./ root@106.53.64.33:/www/boatman-health/server/

echo "🔄 重启服务..."
ssh root@106.53.64.33 "cd /www/boatman-health/server && npm install --production && npx prisma generate && pm2 restart boatman-health --update-env"

echo "✅ 部署完成！"
```

## 常用命令速查

### 本地命令

| 操作 | 命令 |
|------|------|
| 编译 TypeScript | `npm run build` |
| 上传到服务器 | `rsync -avz --delete --exclude='node_modules' --exclude='.env' ./ root@106.53.64.33:/www/boatman-health/server/` |

### 服务器命令

| 数据库迁移 | `npx prisma migrate deploy` |

| 查看日志 | `pm2 logs boatman-health` |
| 查看服务状态 | `pm2 list` |

---

## 注意事项

1. **数据库迁移**：如果有新的 Prisma 迁移，需要在服务器执行：
   ```bash
   npx prisma migrate deploy
   ```

2. **环境变量**：更新不会覆盖服务器上的 `.env` 文件，无需担心配置丢失。

3. **回滚**：如果更新出现问题，可以从 Git 历史中恢复代码并重新部署。

4. **日志检查**：更新后建议检查日志确认服务正常：
   ```bash
   pm2 logs boatman-health --lines 50
   ```
